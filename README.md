## 概要
ボールを操作してゴールを目指すシンプルな3Dアクションゲームです。

**ジャンル:** 3Dアクション
*   **プレイ人数:** 1人
*   **プレイ時間:** 1時間程度
*   **ターゲット層:** カジュアルゲームが好きな方


## 特徴・アピールポイント
*   ポイント1：シンプルな操作性とゲーム性
*   ポイント2：複数のギミック
*   ポイント3：25個のステージ

## 遊び方（操作方法）
### 操作方法
*   **移動:** `W` `A` `S` `D`
*   **メニュー:** `Tab` キー

### ルール
1. ルール：ボールを操作してゴールを目指す

## 開発環境
*   **ゲームエンジン:** Unity 2022.3.34f1
*   **開発言語:** C#
*   **主な使用アセット、素材:**
    *   [Panoramic Cartoon Skybox](https://assetstore.unity.com/packages/2d/textures-materials/sky/panoramic-cartoon-skybox-220659#content)
    *   [UI Samples](https://assetstore.unity.com/packages/essentials/ui-samples-25468)
    *   [Fatality FPS Gaming Font](https://assetstore.unity.com/packages/2d/fonts/fatality-fps-gaming-font-216954)
    *   [2D Casual UI HD](https://assetstore.unity.com/packages/2d/gui/icons/2d-casual-ui-hd-82080)


## 導入手順・起動方法
1. 本リポジトリの [Releases](https://github.com/Kurama-Hiiti/RollingBall/releases) からRolling.Ball.zipファイルをダウンロードします。
2. ダウンロードしたファイルを解凍します。
3. `Rolling Ball.exe` を実行するとゲームが始まります。

**[UnityRoom](https://unityroom.com/games/rollingball_action)にもアップロードしているのでそちらからもプレイできます。**
